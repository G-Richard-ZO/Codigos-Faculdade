    Lista linear ou lista armazena um conjunto de elementos relacionados
    Ex:
        lista de mercado
        lista de contatos



    cada informação que esta na lista é um registro nomeado celula ou elemento
    um desses campos é a chave ( um identificador) que é utilizado para efetuar operações na lista



    uma lista linear L é um conjunto de n elementos (celulas) dispostos em uma sequencia linear
    L = {c1, c2, c3, ..., cn}
    onde a ordem relativa dos elementos é importante



    operações basicas
        Busca
        Inserção (sem restrição como outros TADS)
        Remoção (sem restrição como outros TADS)


    outras operações
        concaenaçao de duas ou mais listas
        separacaao de uma lista em dua ou mais listas
        ordenação dos elementos de uma lista  

    

    IMPLEMENTAÇÃO   


    pode ser implementada de duas maneiras,

        alocação sequencial
            os elementos são armazenados em posições contínuas de memória
            ex: vetores, matrizes
    
        alocação encadeada
            os elementos são armazenados em posições não contínuas de memória

        a escolha depende de fatores como
            - tipo de aplicação
            - quantidade de elementos a serem armazenados
            - operações que serão realizadas com mais frequência
            - restrições de memória, se tem memória sobrando ou não

        celula *p;
        p = lst;

        while(p!=NULL && p->chave != X)
            p = p->prox;

    void busca_remove(int X, celula **lst){

        celula *p, *q;
        p=NULL;
        q=*lst;


        while(q!=NULL && q->chave != X)
            p = q;
            q = q->prox; /*q anda para frente*/


        if (q!=NULL){
            if (p!= NULL){
                p->prox = q->prox
            }else{ 
                *lst = q->prox
            }
            free (q)
        }
        
    }
